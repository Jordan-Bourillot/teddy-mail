# BACKLOG — idées hors scope V1

Toute idée notée ici pendant la build est **non exécutée** dans la mission courante. Elle est à arbitrer plus tard.

## V1.5 — Différenciation

- TL;DR sur thread long (modèle local, ou clé API utilisateur).
- Détection d'engagements + rappels automatiques.
- Adresses jetables natives (alias `xxx@`) — dépendance externe à choisir.
- Calendrier minimaliste (lecture .ics, RSVP).
- Newsletters dans une vue style RSS.
- Éditeur de thème avec export/import JSON.
- Marketplace de thèmes communautaires.

## V2 — Mobile et collaboration

- React Native + UniFFI réutilisant le cœur Rust.
- Boîtes partagées (`support@`, attribution).
- Brouillons co-édités.
- Notes internes attachées aux mails.

## V3 — IA et automation

- IA de réponse semi-automatique (clé utilisateur, on-device).
- Règles automatiques apprises ("tu archives toujours les notifs Linear, je le fais pour toi ?").
- Agrégateur cross-comptes intelligent (classement unifié).

## Idées non priorisées

- Mode lecture longue style article pour newsletters.
- Sons d'envoi/archive optionnels.
- Statistiques personnelles ("temps gagné cette semaine", "boîte vide jour 12").
- Intégration RSS dans l'app (lecture confortable des flux).
- Plugin VS Code pour répondre depuis l'éditeur (devs).

## Anti-features (refusées explicitement)

- Pas de tracking comportemental.
- Pas de pixel d'ouverture côté envoi (par défaut).
- Pas de feed publicitaire injecté en boîte.
- Pas de stockage cloud par défaut sans chiffrement client.
- Pas de "smart compose" qui envoie le brouillon aux serveurs Anthropic/OpenAI sans clé utilisateur.
