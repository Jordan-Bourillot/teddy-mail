# Teddy Mail v0.3.1

Reader-pane upgrades.

## What's new
- **Forward** : Transférer button (or `F` shortcut) opens a draft pre-filled with the message as a quoted block.
- **Quick reply** below the thread : lightweight textarea, ⌘+Entrée sends. No modal needed for short answers.
- **Find in mail** (`⌘F`) : highlights all matches in the reader, jumps with ↑↓ or Shift+Entrée, scrolls to the active hit. Esc closes.
- **Snooze countdown** : threads that are reportés show 🌙 24 min / 3 h / 2 j on their card.
